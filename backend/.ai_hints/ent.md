# Справочник ИИ по фреймворку ENT

Этот документ содержит архитектурные правила и решения для работы с ORM ENT в данном проекте.

## 1. Архитектура Soft Delete (Мягкое удаление)

**ПРОБЛЕМА:** В ENT пакет `schema` не может импортировать сгенерированный пакет `ent` (циклическая зависимость). Это делает невозможным написание хуков мутации внутри схем, если им нужен доступ к клиенту.

**РЕШЕНИЕ (Двухуровневое):**
1.  **Слой Схемы (`ent/schema/`)**:
    *   Определяем только поле `deleted_at`.
    *   Определяем **Интерцептор** (Interceptor) для фильтрации `SELECT`. Интерцепторы безопасны, так как работают с интерфейсами запросов и не требуют импорта `ent`.
2.  **Слой Репозитория (`internal/repositories/pg/`)**:
    *   Определяем **Глобальный Хук** (Runtime Hook) в файле `soft_delete_hook.go`.
    *   Хук перехватывает `Delete` и превращает его в `Update`.
    *   **Регистрация**: Хук регистрируется в `ConnectEnt` через `client.Use()`.

### Универсальные мутации (SetField)
Для обхода строгой типизации Go и отсутствия ковариантности возвращаемых типов (проблема `Client() any`), в глобальных хуках используйте:
```go
mx.SetField("deleted_at", time.Now())
```
Это работает для любой сущности, имеющей данное поле, без необходимости приведения к конкретному типу мутации (например, `*ent.UserMutation`).

## 2. Генерация кода
*   **Команда**: `go generate ./...` из папки `backend`.
*   **Когда**: После любого изменения в `ent/schema/*.go`.
*   **Методы**: Если после добавления поля в миксин пропали методы типа `DeletedAtNotNil`, значит поле должно быть объявлено явно в `StandardMixin` в пакете `schema`.

## 3. Управление ID
*   **Тип**: `string`.
*   **Формат**: `PREFIX-NANOHID`.
*   **Конфигурация**: Префиксы задаются в `ent/schema/common.go`.

## 4. Контекст и фильтрация
*   **SkipSoftDelete**: Для получения удаленных записей используйте `ctx = schema.SkipSoftDelete(ctx)`.
*   **Проброс**: `context.Context` должен передаваться во все методы репозиториев без исключения.

## 5. Типичные ошибки
*   `unexpected mutation type`: Скорее всего, попытка приведения мутации к типу в месте, где этот тип недоступен или не совпадает. Используйте `SetField`.
*   `import cycle not allowed`: Попытка импорта `ent` внутри `schema`. Выносите логику в `internal/repositories/pg` или `internal/entutil` (если там нет импорта `ent`).
